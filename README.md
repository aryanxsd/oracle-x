# ORACLE X — Web Application

Enterprise risk investigation interface for ORACLE X (synthetic banking fraud / AML data).
Next.js 16 · React 19 · TypeScript · Tailwind CSS v4. Snowflake (`ORACLE_X`) is the single source of truth;
the backend (risk engine, evidence chain, agents, evaluation) is frozen and is only *read* by this app.

## Architecture

```
Browser (React client components)
   │  fetch /api/*  (no Snowflake credentials ever reach the browser)
   ▼
Next.js server (route handlers + server components)
   ├─ lib/server/guards.ts        input validation, graph-limit clamping (≤3 hops, ≤200 paths)
   ├─ lib/server/queries.ts       allow-listed, bind-parameter SQL against frozen objects
   ├─ lib/server/cortex-agent.ts  Cortex Agents REST API (ORACLE_ORCHESTRATOR :run, streamed)
   └─ lib/snowflake.ts            template SDK client (SPCS OAuth / local CLI connection)
   ▼
Snowflake ORACLE_X  (INTEL, CASES, EVAL, AGENTS, SEMANTIC, SEARCH)
```

`lib/data-sources.ts` lists the backend object behind every screen; each page shows it under
"Where this screen's data comes from".

## Screens

Command Center (live) · Investigations · Entity Graph · Risk Intelligence · Evidence · Scenarios ·
Similar Cases · Case Files · Agent Trace · Evaluation. Screens other than the Command Center are shells
until their data wiring milestone.

## API routes

| Route | Backend |
|---|---|
| `GET /api/health` | `CURRENT_ROLE()`, `CURRENT_WAREHOUSE()` |
| `GET /api/radar` | `INTEL.V_ENTITY_RISK_INTELLIGENCE` |
| `GET /api/entities/search?q=` | `AGENTS.TOOL_RESOLVE_ENTITY` |
| `GET /api/investigations/recent` | `CASES.COUNCIL_RUNS` |
| `POST /api/agent/ask` | Cortex Agent REST `ORACLE_X.AGENTS.ORACLE_ORCHESTRATOR:run` (SSE) |

## Local development

```bash
npm install
npm run dev
```

`.env.local` (git-ignored, no secrets) selects the Snowflake CLI connection and pins
`ORACLE_X_ADMIN` / `ORACLE_X_WH` / `ORACLE_X`. Authentication comes from `~/.snowflake`.

```bash
npm test        # vitest (guards tests; template snowflake tests assume POSIX paths)
npm run build   # production build (standalone output)
```

## Deployment

Deployed as a Snowflake App (SPCS application service) with `snow app setup` / `snow app deploy`.
`app.yml` is the build-only manifest; the deployment manifest is generated by `snow app setup` at deploy time.
